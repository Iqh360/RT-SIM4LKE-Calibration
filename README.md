## Placebo, worse, or a bill you have not received yet

A bought tune lands in one of three places. Only one of them is ever advertised, and none of them can
be told apart by how the car pulls on a test drive.

**01 — Placebo.** Tables edited, exported, flashed — and never read by the firmware. The car is
exactly what it was. You paid for a file that does nothing, and the placebo does the rest: it always
feels a little sharper after you have handed over money.

**02 — Worse.** Throttle response flattened, a limiter lifted that should have stayed, timing raised
into cells where knock control now fights it constantly. The car is slower, hotter, or both, and
nothing on the dash explains why.

**03 — Working, against the engine.** Lean under load, or advance the engine was never built for. It
pulls hard, so it feels like the best money you ever spent. The bill arrives later, at full throttle,
in fourth gear.

**None of it shows up as a fault code.** The ECU does exactly what the file says. If the file says
something wrong, it does it perfectly, every time, until something lets go.

## Four things your file will never tell you

- **A table that does nothing.** Edited, exported, flashed — never read by the firmware. The car
  drives exactly as before. You paid for a change that does not exist.
- **The table nobody touched.** Everything around it was raised, but the one limit in the middle is
  still stock, so the extra never arrives. The file does not admit it.
- **Values past the safe band.** The grid accepts the number. That is not the same as the engine
  accepting it at 6,000 rpm in fourth gear.
- **A scalar that decides everything.** One value, sitting alone, is what actually limits the car.
  Miss it and every table that was edited is decoration.
