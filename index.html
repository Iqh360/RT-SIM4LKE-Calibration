03 · what a file hides

A calibration file is not one table. And it does not always agree with itself.

Parts of a SIM4LKE image repeat, and the repeats are not always identical. A change that ignores that is a change that half-works: applied where the file expects it, missed where the firmware actually reads. We map every region before we judge a single cell.
